# FX Lab — CSS Effects Library (Complete Project)

164 pure-CSS effects with live previews, copyable code, favorites, search/filter,
dark mode, 10 website color palettes (with hex codes + live previews),
feedback system (saved to SQLite) and security hardening.

## Tech Stack
- Next.js 16 (App Router) + TypeScript 5
- Tailwind CSS 4 + shadcn/ui (New York) + lucide-react + framer-motion
- Prisma ORM + SQLite (db/custom.db)

## How to Run

1. Extract the zip, then open a terminal inside the extracted folder.

2. Install dependencies (any ONE of these):

   ```bash
   bun install
   # or
   npm install
   # or
   pnpm install
   ```

3. Create the database from the Prisma schema:

   ```bash
   bunx prisma db push
   # or
   npx prisma db push
   ```

   (The included db/custom.db already has data, but this step guarantees
   the Prisma client is generated for your machine.)

4. Start the dev server:

   ```bash
   bun run dev
   # or
   npm run dev
   ```

5. Open http://localhost:3000

## Notes

- `.env` in the archive uses a relative DB path (file:../db/custom.db).
  It works as long as you keep the original folder structure
  (db/ next to prisma/). To use an absolute path instead, set:
  DATABASE_URL=file:/full/path/to/db/custom.db
- `node_modules` and `.next` are NOT included (regenerated by install/build).
- Security headers are configured in next.config.ts (preview-iframe safe).
